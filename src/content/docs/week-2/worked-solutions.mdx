## 2. Three unknowns, one solution

<StepReveal
	problem={"x + y + z = 6\n2x + 3y + z = 11\nx − y + 2z = 5"}

## 3. Infinitely many solutions

<StepReveal
	problem={"x + 2y − z = 3\n2x + 5y + z = 8\nx + 3y + 2z = 5"}

## 4. For which b is it consistent?

<StepReveal
	problem={"x − y + 2z = 1\n2x − y + 3z = 4\nx + y = b"}
