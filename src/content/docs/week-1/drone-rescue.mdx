## Question 1

<Exercise
	q="Drone A leaves P(1, 2, 3) at t = 0 and has velocity (2, 1, 2). Write its position A(t). When does it reach rooftop Q(7, 5, 9)?"
	hint="Position = start + t × velocity. All three components must agree."
	solution={'A(t) = (1, 2, 3) + t(2, 1, 2)\n1 + 2t = 7  →  t = 3\ncheck: (7, 5, 9) ✓   so t = 3 min'}
/>

## Question 2

<Exercise
	q="How far does drone A fly from P to Q? Give the unit vector in its direction of travel."
	hint="Find PQ first."
	solution={'PQ = (6, 3, 6)\n|PQ| = √81 = 9 units\nunit vector = (2/3, 1/3, 2/3)'}
/>

## Question 3

<Exercise
	q="A rescue beacon is at R(6, 4, 6). Show whether drone A flies through it."
	hint="Solve one component for t, then test the others."
	solution={'1 + 2t = 6  →  t = 5/2\ny = 2 + 5/2 = 9/2 ≠ 4\nIt does not pass through R.'}
/>

## Question 4

<Exercise
	q="Find the time at which drone A is closest to the beacon R, and that shortest distance."
	hint="At the closest point, A(t) − R is perpendicular to the velocity."
	solution={'A(t) − R = (2t − 5, t − 2, 2t − 3)\ndot with (2, 1, 2):  9t − 18 = 0  →  t = 2\noffset = (−1, 0, 1)\ndistance = √2'}
/>

## Question 5

<Exercise
	q="A flat safety net passes through C(1, 5, 4), D(3, 2, 6) and E(5, 3, 4). Find its Cartesian equation."
	hint="Cross two edge vectors, then simplify the normal."
	solution={'CD = (2, −3, 2),  CE = (4, −2, 0)\nCD × CE = (4, 8, 8), so n = (1, 2, 2)\nx + 2y + 2z = 19'}
/>

## Question 6

<Exercise
	q="The net extends over the whole plane. When and where does drone A pass through it?"
	hint="Substitute A(t) into the plane equation."
	solution={'(1+2t) + 2(2+t) + 2(3+2t) = 19\n11 + 8t = 19  →  t = 1\npoint (3, 3, 5)'}
/>

## Question 7

<Exercise
	q="Let α be the angle between drone A's path and the net. Find sin α exactly."
	hint="The angle with a plane uses sine, because n is perpendicular to the plane."
	solution={'sin α = |v·n| / (|v||n|)\n      = |2 + 2 + 4| / (3 × 3)\n      = 8/9'}
/>

## Question 8

<Exercise
	q="Drone B has position B(t) = (10, 1, 4) + t(−2, 0, 1). Show that the two flight paths are skew, and find the shortest distance between the paths."
	hint="Use different parameters to test for intersection. Then use the common normal."
	solution={'Directions are not multiples, so not parallel.\ny: 2 + t = 1 → t = −1\nx: −1 = 10 − 2s → s = 11/2\nz: A gives 1, B gives 19/2. No intersection: skew.\n(Here the whole lines are tested, so t may be negative.)\nn = (2,1,2) × (−2,0,1) = (1, −6, 2)\nB(0) − P = (9, −1, 1)\nd = |9 + 6 + 2| / √41 = 17/√41'}
/>

## Question 9

<Exercise
	q="Both drones launch at t = 0. When are the drones themselves closest, and how close? If they must stay at least 3 units apart, are they safe? Why is this distance not the same as in question 8?"
	hint="Now both use the same t. Minimise the squared distance."
	solution={'A − B = (4t − 9, t + 1, t − 1)\n|A − B|² = 18t² − 72t + 83\n          = 18(t − 2)² + 11\nclosest at t = 2, distance √11\n√11 > √9 = 3, so they are safe.\nQuestion 8 lets each drone be at any time; here both times must match.'}
