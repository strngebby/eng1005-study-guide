## 3. A repeated eigenvalue in 3 × 3

<StepReveal
	problem={"A = [2 0 0]\n    [1 3 1]\n    [1 1 3]"}
	steps={[["Expand along row 1","(2 − λ)[(3 − λ)² − 1] = 0"],["Factorise","(2 − λ)(2 − λ)(4 − λ) = 0\nλ = 2 (algebraic multiplicity 2), λ = 4"],["λ = 2","all rows reduce to x + y + z = 0\ntwo free variables:\nv = (1, −1, 0) and (1, 0, −1)\ngeometric multiplicity 2"],["λ = 4","row 1: −2x = 0  →  x = 0\nrow 2: −y + z = 0\nv = (0, 1, 1)"],["Conclusion","Three independent eigenvectors, so A is diagonalisable."]]}
/>

## 4. Diagonalise, then find Aⁿ

<StepReveal
	problem={"A = [3 1]\n    [0 2]"}
