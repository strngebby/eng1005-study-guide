## 2. Coupled equations

<StepReveal
	problem={"f = x³ + y³ − 3xy"}
	steps={[["Set the gradient to zero","y = x²  and  x = y²"],["Substitute","x⁴ = x  →  x = 0 or 1"],["Hessian","H = [6x −3; −3 6y]"],["Classify","(0, 0): det = −9, saddle\n(1, 1): det = 27, fxx = 6, minimum −1"]]}
/>

## 3. Absolute extrema on a disc

<StepReveal
	problem={"f = x² + y² − 2y on x² + y² ≤ 4"}
	steps={[["Inside","∇f = (2x, 2y − 2) = 0  →  (0, 1), f = −1"],["Boundary","x² = 4 − y², so f = 4 − 2y with −2 ≤ y ≤ 2"],["Compare","maximum 8 at (0, −2)\nminimum −1 at (0, 1)"]]}
/>

## 4. A constrained maximum

<StepReveal
	problem={"Maximise xy subject to x + 4y = 8."}
	steps={[["Gradients","(y, x) = λ(1, 4)"],["Relate","x = 4λ and y = λ, so x = 4y"],["Constraint","8y = 8  →  y = 1, x = 4"],["Value","4"]]}
/>

## 5. Parameterise an ellipse

<StepReveal
